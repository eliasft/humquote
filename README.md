# HUMQuote

Bulk electricity pricing for HUM Energy's commercial and industrial (C&I) customers in
the NEM: three-year contract quotes built from ASX Energy base futures plus network
charges, and a bulk price index over time.

Three apps share the same data and calculations:

- **Streamlit app**: `HUM.py` (entry point), `quote.py` and `pages/`, with the pricing
  core in `humquote_core.py`.
- **Web versions A and B** (GitHub Pages): `site/a/` and `app-b/`, with the core in
  `app-b/src/core` (tested to give the same results as the Python core).

Data:

- `data/asx_futures.csv`: ASX settlement prices, updated each trading day by the
  "Update ASX Futures Data" workflow (`update_db.py`). See `data/README.md`.
- `reference-data/tariffs.json`: network tariffs, generated by
  `reference-data/make_tariffs.py` from each network's published price list. What's
  researched, assumed or still a placeholder is in `reference-data/PLACEHOLDERS.md`.
